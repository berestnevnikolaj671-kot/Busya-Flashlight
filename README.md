# Busya-Flashlight
# Минамалистичное приложение фонарика.


Busya™ Flashlight 🔦Простой, легкий и абсолютно безопасный фонарик для вашего смартфона. Никакой слежки, никакого сбора данных, только свет.О проектеМногие приложения-фонарики в современных маркетах требуют лишние разрешения (доступ к контактам, геолокации, микрофону) и показывают навязчивую рекламу. Busya™ Flashlight решает эту проблему. Приложение запрашивает исключительно доступ к камере (это технически необходимо для включения вспышки) и больше ничего.Главные особенностиБезопасность: Никакой слежки и сбора личных данных.Автономность: Умеет работать оффлайн (сеть нужна только для перехода по юридическим ссылкам).Никакой рекламы: Чистый интерфейс без встроенных покупок и баннеров.Мультиязычность: Полный и точный перевод интерфейса на 31 язык!Кастомизация: Поддержка светлой и темной тем оформления, красивая анимация света на экране.Открытый код: Все функции написаны на чистом HTML/CSS/JS в одном файле.Примечание о FirebaseЕсли вы распакуете итоговый APK-файл, вы можете обнаружить там библиотеки Firebase. Они автоматически добавляются сборщиком оболочки по умолчанию. Наш код фонарика их не использует и не отправляет никаких данных на серверы аналитики. Если вы сомневаетесь, вы можете полностью отключить приложению доступ в интернет в настройках вашего смартфона — фонарик продолжит работать идеально.By BusyaTM - protect your privacyДанное приложение подчиняется законам Российской Федерации.Все упомянутые сторонние товарные знаки принадлежат их законным владельцам.
